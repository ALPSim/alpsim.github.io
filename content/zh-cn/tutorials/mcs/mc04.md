除了能量、磁化强度这类热力学平均值之外，量子蒙特卡洛模拟还可以测量空间关联函数及其傅里叶变换。
本教程在小正方格子上，用有向圈随机级数展开程序对 $S = 1/2$ 海森堡模型演示这些测量。

自旋-自旋关联函数 $C(\mathbf{r}) = \langle S^z_0 S^z_\mathbf{r} \rangle$ 描述了相距 $\mathbf{r}$ 的两个格点上自旋取向之间的关联。
对于低温下的反铁磁海森堡模型，关联随距离交替变号，反映了系统趋向奈尔序的倾向。
结构因子 $S(\mathbf{q}) = \sum_\mathbf{r} e^{i\mathbf{q}\cdot\mathbf{r}} C(\mathbf{r})$ 是关联函数的傅里叶变换；它在反铁磁波矢 $\mathbf{q} = (\pi, \pi)$ 处出现峰值。

## 二维海森堡正方格子

我们在 $4 \times 4$ 正方格子上模拟 $S = 1/2$ 海森堡模型，温度取 $T = 0.3$，并加上一个小磁场 $h = 0.1$ 以弱破缺自旋旋转对称性。
较小的系统尺寸使模拟运行得很快；不过在这个尺度上，有限尺寸效应是显著的。

### 命令行

参数文件 <a class="alps-download" href="https://raw.githubusercontent.com/ALPSim/ALPS/master/tutorials/mc-04-measurements/parm4" data-filename="parm4" target="_blank" rel="noopener">`parm4`</a> 在标准参数之外，还开启了三个额外的测量开关：

```
MODEL="spin"
LATTICE="square lattice"
local_S=1/2
MEASURE[Correlations]=true
MEASURE[Structure Factor]=true
MEASURE[Green Function]=true
THERMALIZATION=10000
SWEEPS=500000
J=1
L=4
W=4
T=0.3
{h=0.1;}
```

`MEASURE[Correlations]` 记录所有格点对的 $\langle S^z_i S^z_j \rangle$。
`MEASURE[Structure Factor]` 记录所有与该晶格相容的波矢处的 $S(\mathbf{q})$。
`MEASURE[Green Function]` 记录等时非对角关联 $G(\mathbf{r}) = \langle S^+_0 S^-_\mathbf{r} \rangle$，对应可观测量 `Green's Function`，以位移 $\mathbf{r}$ 为指标。尽管名为格林函数，它是距离的函数，而不是虚时的函数。对于各向同性的海森堡模型，$\mathbf{r} \neq 0$ 时 $|G(\mathbf{r})| = 2|\langle S^z_0 S^z_\mathbf{r} \rangle|$（此处只是近似成立，因为 $h = 0.1$ 微弱地破坏了自旋旋转对称性）。注意，`dirloop_sse` 在反铁磁体上只给出其大小：所有值都是正的，而真实的 $\langle S^+_0 S^-_\mathbf{r} \rangle$ 是交替变号的（[ALPS #390](https://github.com/ALPSim/ALPS/issues/390)）。

转换并运行：

```
parameter2xml parm4
dirloop_sse --Tmin 10 --write-xml parm4.in.xml
```

`--Tmin 10` 把检查点间隔设为 10 秒；`--write-xml` 会写出 XML 输出文件，pyalps 可以把它与 HDF5 结果一起读取。

### Python

脚本 <a class="alps-download" href="https://raw.githubusercontent.com/ALPSim/ALPS/master/tutorials/mc-04-measurements/tutorial4.py" data-filename="tutorial4.py" target="_blank" rel="noopener">`tutorial4.py`</a>：

```Python
import pyalps

parms = [{
    'LATTICE'                   : "square lattice",
    'MODEL'                     : "spin",
    'MEASURE[Correlations]'     : True,
    'MEASURE[Structure Factor]' : True,
    'MEASURE[Green Function]'   : True,
    'local_S'                   : 0.5,
    'T'                         : 0.3,
    'J'                         : 1,
    'THERMALIZATION'            : 10000,
    'SWEEPS'                    : 500000,
    'L'                         : 4,
    'W'                         : 4,
    'h'                         : 0.1
}]

input_file = pyalps.writeInputFiles('parm4', parms)
pyalps.runApplication('dirloop_sse', input_file, Tmin=10)
```

### 计算结果的读取

从输出文件中载入全部测量结果并打印出来：

```Python
import pyalps

data = pyalps.loadMeasurements(pyalps.getResultFiles(prefix='parm4'))

for s in pyalps.flatten(data):
    if len(s.x) == 1:
        print(s.props['observable'], ':', s.y[0])
    else:
        for (x, y) in zip(s.x, s.y):
            print(s.props['observable'], x, ':', y)
```

标量可观测量（能量、磁化强度、磁化率）打印在一行里。
矢量可观测量（关联函数、结构因子、格林函数）则每个条目占一行，并在数值旁边给出其指标——位移 $\mathbf{r}$ 或波矢 $\mathbf{q}$。

### 绘制自旋-自旋关联

载入 `Spin Correlations` 可观测量。矢量可观测量以单个 DataSet 返回：`x` 的每个元素是相对格点 0 的位移 $(d_x, d_y)$，`y` 是带误差棒的数值。`pyalps.collectXY` 只能把多次运行的标量可观测量收集起来，因此距离直接由 `x` 计算：

```Python
import numpy as np
import pyalps
import matplotlib.pyplot as plt

L = 4
data = pyalps.loadMeasurements(pyalps.getResultFiles(prefix='parm4'), 'Spin Correlations')
corr = data[0][0]

# corr.x 的每个元素是相对格点 0 的位移 (dx, dy)；
# 在周期边界条件下，距离取最近镜像
d = np.minimum(corr.x, L - corr.x)
r = np.hypot(d[:, 0], d[:, 1])
C     = np.array([y.mean for y in corr.y])
C_err = np.array([y.error for y in corr.y])

plt.figure()
plt.errorbar(r, C, C_err, fmt='o')
plt.axhline(0, color='gray', lw=0.5)
plt.xlabel('Distance $r$')
plt.ylabel('$\\langle S^z_0 S^z_r \\rangle$')
plt.title('Spin correlations, $4\\times 4$ Heisenberg model')
plt.tight_layout()
plt.show()
```

![](/figs/mcs04correlations.png)

关联应当随距离交替变号，其中最近邻的值为负（反铁磁）。在 $4 \times 4$ 晶格上，直到最大距离其大小都保持在约 $0.06$–$0.11$。

### 绘制结构因子

对 `Spin Structure Factor` 而言，`x` 是晶格允许的波矢 $(q_x, q_y)$。打印每个波矢处的 $S(\mathbf{q})$ 并找出最大值：

```Python
import numpy as np
import pyalps

data = pyalps.loadMeasurements(pyalps.getResultFiles(prefix='parm4'), 'Spin Structure Factor')
sq = data[0][0]

# sq.x 的每个元素是一个波矢 (qx, qy)
for q, s in zip(sq.x, sq.y):
    print('q/pi = (%4.2f, %4.2f):  S(q) = %s' % (q[0] / np.pi, q[1] / np.pi, s))

i = np.argmax([s.mean for s in sq.y])
print('largest at q/pi = (%4.2f, %4.2f): %s' % (sq.x[i][0] / np.pi, sq.x[i][1] / np.pi, sq.y[i]))
```

最大值应当出现在反铁磁波矢 $\mathbf{q} = (\pi, \pi)$ 处，它对应于奈尔序中交替排列的自旋图样。

## 思考题

- 结构因子在哪个波矢处最大？这对应于怎样的自旋关联图样？
- 关联 $\langle S^z_0 S^z_r \rangle$ 如何随距离 $r$ 衰减？在整个 $4 \times 4$ 格子范围内它们是否都还显著？
- 在更低的温度下重复模拟，例如 $T = 0.1$。关联函数和结构因子会如何变化？
- 把系统尺寸增大到 $L = 8$。结构因子的峰值如何随 $L$ 标度？这告诉你在有限温度下是否存在长程序？
- 这里测量的格林函数 $\langle S^+_0 S^-_\mathbf{r} \rangle$ 是一个等时量。把它与 $\langle S^z_0 S^z_\mathbf{r} \rangle$ 比较：对于各向同性的海森堡模型，两者有什么关系？为什么在 $h = 0.1$ 时二者略有不同？

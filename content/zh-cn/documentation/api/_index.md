本手册汇总了 ALPS 教程中用到的 `pyalps` 函数。Python API 部分的结构如下：

- [运行应用程序](runapp)：用于运行 ALPS 应用程序的函数
- [加载数据](loadat)：用于加载特定应用程序所生成测量结果的函数
- [评估](eval)：用于数据分析的通用函数，例如收集结果和绘图。

请参阅 [ALPS 应用程序教程](../../../../tutorials)，了解这些函数在实际模拟中如何使用。例如：如何扫描多个温度并将平均磁化强度绘制为温度的函数，或者如何外推有限尺寸效应。

エネルギーや磁化のような熱力学的平均値だけでなく、QMC シミュレーションでは空間相関関数とそのフーリエ変換も測定できます。
このチュートリアルでは、小さな正方格子上の $S = 1/2$ ハイゼンベルク模型に対して、有向ループ SSE コードを用いてこれらの測定を実演します。

スピン–スピン相関関数 $C(\mathbf{r}) = \langle S^z_0 S^z_\mathbf{r} \rangle$ は、$\mathbf{r}$ だけ離れた 2 つのサイトにおけるスピンの向きがどれだけ相関しているかを表します。
低温の反強磁性ハイゼンベルク模型では、相関は距離とともに符号を交互に変え、ネール秩序へ向かう傾向を反映します。
構造因子 $S(\mathbf{q}) = \sum_\mathbf{r} e^{i\mathbf{q}\cdot\mathbf{r}} C(\mathbf{r})$ は相関関数のフーリエ変換であり、反強磁性波数 $\mathbf{q} = (\pi, \pi)$ でピークを持ちます。

## 2 次元ハイゼンベルク正方格子

$4 \times 4$ の正方格子上の $S = 1/2$ ハイゼンベルク模型を、温度 $T = 0.3$、スピン回転対称性をわずかに破るための小さな磁場 $h = 0.1$ のもとでシミュレートします。
システムサイズが小さいためシミュレーションは高速ですが、このスケールでは有限サイズ効果が顕著です。

### コマンドライン

パラメータファイル <a class="alps-download" href="https://raw.githubusercontent.com/ALPSim/ALPS/master/tutorials/mc-04-measurements/parm4" data-filename="parm4" target="_blank" rel="noopener">`parm4`</a> は、標準的なパラメータに加えて 3 つの測定フラグを有効にします。

```
MODEL="spin"
LATTICE="square lattice"
local_S=1/2
MEASURE[Correlations]=true
MEASURE[Structure Factor]=true
MEASURE[Green Function]=true
THERMALIZATION=10000
SWEEPS=500000
J=1
L=4
W=4
T=0.3
{h=0.1;}
```

`MEASURE[Correlations]` はすべてのサイト対について $\langle S^z_i S^z_j \rangle$ を記録します。
`MEASURE[Structure Factor]` は格子と整合するすべての波数における $S(\mathbf{q})$ を記録します。
`MEASURE[Green Function]` は等時刻の非対角相関 $G(\mathbf{r}) = \langle S^+_0 S^-_\mathbf{r} \rangle$ を測定量 `Green's Function` として記録し、変位 $\mathbf{r}$ を添字とします。名前に反して、これは距離の関数であり、虚時間の関数ではありません。等方的なハイゼンベルク模型では、$\mathbf{r} \neq 0$ に対して $|G(\mathbf{r})| = 2|\langle S^z_0 S^z_\mathbf{r} \rangle|$ が成り立ちます（ここでは $h = 0.1$ がスピン回転対称性をわずかに破るため近似的にのみ成り立ちます）。なお、`dirloop_sse` は反強磁性体では大きさしか返しません。真の $\langle S^+_0 S^-_\mathbf{r} \rangle$ は符号が交互に変わりますが、値はすべて正になります（[ALPS #390](https://github.com/ALPSim/ALPS/issues/390)）。

変換して実行します。

```
parameter2xml parm4
dirloop_sse --Tmin 10 --write-xml parm4.in.xml
```

`--Tmin 10` はチェックポイント間隔を 10 秒に設定します。`--write-xml` は XML 出力ファイルを書き出し、pyalps は HDF5 の結果と併せてこれを読み込めます。


### 結果の評価

出力ファイルからすべての測定結果を読み込み、表示します。

```Python
import pyalps

data = pyalps.loadMeasurements(pyalps.getResultFiles(prefix='parm4'))

for s in pyalps.flatten(data):
    if len(s.x) == 1:
        print(s.props['observable'], ':', s.y[0])
    else:
        for (x, y) in zip(s.x, s.y):
            print(s.props['observable'], x, ':', y)
```

スカラー量（エネルギー、磁化、帯磁率）は 1 行で表示されます。
ベクトル量（相関関数、構造因子、グリーン関数）は 1 エントリごとに 1 行で表示され、その添字——変位 $\mathbf{r}$ または波数 $\mathbf{q}$——が値とともに示されます。

### スピン–スピン相関のプロット

`Spin Correlations` の測定量を読み込みます。ベクトル量は 1 つの DataSet として返され、`x` の各要素は格点 0 からの変位 $(d_x, d_y)$、`y` は誤差付きの値です。`pyalps.collectXY` は複数の実行にわたるスカラー量しか集めないので、距離は `x` から直接計算します。

```Python
import numpy as np
import pyalps
import matplotlib.pyplot as plt

L = 4
data = pyalps.loadMeasurements(pyalps.getResultFiles(prefix='parm4'), 'Spin Correlations')
corr = data[0][0]

# corr.x の各要素は格点 0 からの変位 (dx, dy)。
# 周期境界条件では距離に最近接イメージを使う
d = np.minimum(corr.x, L - corr.x)
r = np.hypot(d[:, 0], d[:, 1])
C     = np.array([y.mean for y in corr.y])
C_err = np.array([y.error for y in corr.y])

plt.figure()
plt.errorbar(r, C, C_err, fmt='o')
plt.axhline(0, color='gray', lw=0.5)
plt.xlabel('Distance $r$')
plt.ylabel('$\\langle S^z_0 S^z_r \\rangle$')
plt.title('Spin correlations, $4\\times 4$ Heisenberg model')
plt.tight_layout()
plt.show()
```

![](/figs/mcs04correlations.png)

相関は距離とともに符号を交互に変え、最近接の値は負（反強磁性的）になるはずです。$4 \times 4$ 格子では、最大距離まで大きさは約 $0.06$–$0.11$ にとどまります。

### 構造因子のプロット

`Spin Structure Factor` では、`x` は格子で許される波数ベクトル $(q_x, q_y)$ です。各波数での $S(\mathbf{q})$ を表示し、最大値を探します。

```Python
import numpy as np
import pyalps

data = pyalps.loadMeasurements(pyalps.getResultFiles(prefix='parm4'), 'Spin Structure Factor')
sq = data[0][0]

# sq.x の各要素は波数ベクトル (qx, qy)
for q, s in zip(sq.x, sq.y):
    print('q/pi = (%4.2f, %4.2f):  S(q) = %s' % (q[0] / np.pi, q[1] / np.pi, s))

i = np.argmax([s.mean for s in sq.y])
print('largest at q/pi = (%4.2f, %4.2f): %s' % (sq.x[i][0] / np.pi, sq.x[i][1] / np.pi, sq.y[i]))
```

最大値は反強磁性波数 $\mathbf{q} = (\pi, \pi)$ に現れるはずで、これはネール秩序の交互に並んだスピン配列に対応します。

## 問題

- 構造因子が最大になるのはどの波数でしょうか。これはどのようなスピン相関のパターンに対応しますか。
- 相関 $\langle S^z_0 S^z_r \rangle$ は距離 $r$ とともにどのように減衰しますか。$4 \times 4$ 格子全体にわたって有意なままでしょうか。
- より低い温度、たとえば $T = 0.1$ でシミュレーションを繰り返してください。相関と構造因子はどう変わりますか。
- システムサイズを $L = 8$ に増やしてください。構造因子のピークは $L$ に対してどのようにスケールしますか。このことは有限温度における長距離秩序の有無について何を示しますか。
- ここで測定したグリーン関数 $\langle S^+_0 S^-_\mathbf{r} \rangle$ は等時刻の量です。これを $\langle S^z_0 S^z_\mathbf{r} \rangle$ と比べてみましょう。等方的なハイゼンベルク模型では両者はどのような関係にあるでしょうか。また、$h = 0.1$ ではなぜわずかに異なるのでしょうか。

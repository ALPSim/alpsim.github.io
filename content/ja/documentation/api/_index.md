このマニュアルには、ALPS チュートリアルで使われている `pyalps` 関数の概要がまとめられています。Python API のセクションは次のように構成されています。

- [アプリケーションの実行](runapp)：ALPS アプリケーションを実行するための関数
- [データの読み込み](loadat)：特定のアプリケーションが生成した測定結果を読み込むための関数
- [評価](eval)：結果の収集やプロットなど、データ解析を行うための汎用関数

これらの関数が実際のシミュレーションでどのように使われるかについては、[ALPS アプリケーションのチュートリアル](../../../../tutorials)を参照してください。例えば、複数の温度をスキャンして平均磁化を温度の関数としてプロットする方法や、有限サイズ効果を外挿する方法などがあります。
